# 待测试

## New API 应用板块对接（APP_KEY=canvas）

把本应用作为 New API「应用」板块的小程序接入：宿主负责登录与计费，应用不再自建账号体系。

### 已实现

- **平台会话**：`POST /api/session/exchange` 用一次性启动码换本应用会话；
  `GET /api/session/config` 返回授权页地址（无需登录，游客也要能拿到）；
  `GET /api/session` / `POST /api/session/quota` / `DELETE /api/session/platform` 管状态。
- **密钥只留服务端**：平台签发的 `sk-` 存在独立的 `platform_links` 表，`json:"-"`，
  永不进浏览器；前端所有模型调用经应用后端转发。
- **渠道解析顺序**：用户自带渠道 → 平台会话渠道 → 系统渠道。平台会话渠道
  由 `PlatformRelayChannel` 合成，复用既有代理链路，所以 relay 的
  401/402/429/403 语义、流式转发、错误脱敏都不用重写。
- **401 是唯一的撤销信号**：命中时立即删除该用户在本应用的全部平台会话，
  不重试、不回退到别的凭据；402/429/403 不动会话。
- **登录门槛在动作处**：`requirePlatformLogin(intent)` 把 `returnPath` 与 `intent`
  编进 base64 `state`；回调顺序固定为解 state → 换会话 → 按 returnPath 跳回 → 按 intent 继续。
- **不拿 message 做分支**：响应没有 `code` 时归为 `app.error_unspecified`，
  原文进 `detail`，提示语指向管理员而不是让用户白跑一趟换启动码。
- **模型列表自动下发**：平台用户的可选模型来自平台，不是本应用后台配置的渠道。
  `GET /api/settings` 带令牌时会按身份把 `modelChannel` 整体换成平台那一份
  （一条 `id=platform` 的渠道 + 平台 `/v1/models` 的结果），并把
  `allowCustomChannel` 置假、`allowUserRemoteChannel` 置真，让前端自然落在云端模式。
  管理员不需要在应用后台配任何渠道，用户点进来就有模型可选。
  模型列表按用户缓存 5 分钟；取不到时降级为空列表，不让页面打不开。

### 已知限制

- 应用内「退出登录」只清本应用会话，**不动**平台密钥与授权记录（契约硬约束 §4）。
- 应用不自行续期凭据、不主动撤销授权、不接收断开通知（v1 不提供）。
- 上架时 `model_limits` 只填真正被调用的生图/文本模型，留空等于不限制。
- 平台用户的模型列表只反映平台开放了什么，不区分能力；生图/视频/文本由前端按模型名
  分类，名字不在前端启发式规则里的模型可能落进「文本」一类。

## 平台契约 v3：多授权项（多密钥）

平台把「一张密钥」升级为「一组授权项（grant）」，每条 grant 固定 `(分组, 模型集合)`
并对应一张专用 `sk-`。应用侧按模型把请求路由到对应密钥。

### 已实现

- **授权项落库**：新增 `platform_grants` 表，按 `(user_id, grant_key)` 唯一；
  密钥列 `json:"-"`，永不返回前端。每次 exchange 用平台返回值整体替换，
  平台侧增删 grant 后本地不残留死密钥。
- **exchange 解析 grants**：优先读 `grants[]`；平台仍是 v1（只有顶层 `api_key`）时
  落成一条 `legacy` 授权项，老部署行为不变。
- **跨密钥路由**：`selectAIRequestChannel` 按模型选 grant —— 精确命中声明的模型面，
  多条命中按 priority、grant key 排序；`legacy`（声明面为空）只做兜底且永远排在后面。
  没有任何 grant 覆盖该模型时直接报「该模型不在本应用的授权范围内」，
  **不回退到别的密钥**，否则会绕过分组边界。
- **模型目录合并**：`PlatformModels` 并行拉取每张密钥的 `/v1/models` 后合并去重；
  单张失败时退回它声明的模型面。缓存键包含 grant 集合，授权项变化后自动重取。
- **401 语义收窄**：单张密钥 401 只把对应 grant 标为 `revoked`，其他 grant 继续可用；
  只有全部 grant 都失效才清会话。402/429/403 一律不动凭据。
- **状态接口**：`GET /api/session` 增加 `grants` 摘要（分组、模型、状态，无密钥）。
